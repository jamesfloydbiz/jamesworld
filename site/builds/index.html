CCAT Trainer

Active

A single-page trainer for the CCAT cognitive aptitude test. Four tabs: Practice (adaptive drill with Leitner-boxed spaced repetition), Exam (50Q / 15:00 countdown, no going back, category-weighted, difficulty-ramped, focus-loss warning), Learning (flashcards with SM-2-lite for the memorizable stuff — squares, cubes, fractions, formulas, roots, traps), and Stats (rolling accuracy, Leitner distribution, exam history, readiness gauge). All state in localStorage — no backend, no login.
